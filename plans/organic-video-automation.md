# Plan: organic-video-automation
Spec: specs/organic-video-automation.md
Architect verdict: PASS

## Architecture
Create a durable, hash-bound collection task. A separately scoped external PERSONAL_AGENT claims the task, uses independently owner-authorized tools or a permitted API for public-post metadata, and submits exact observations and failures. Never silently inherit WMM credentials or capture private communications. The existing collection is a sink, not a live source. Apply unchanged viral policy to the latest up-to-20 comparable posts with at least 10, then separate freshness and relevance from foreign-media reuse rights. ORIGINAL_RECREATION uses an original script and ALLOWED assets even when foreign-footage rights are unknown; LICENSED_EDIT requires current reuse rights. An incomplete agent run is not completed discovery. Existing internal tool-free agents are not widened.

Use owned demo footage and a versioned Hypit media segment, private verified snapshot, revocation recheck and committed provenance. Bind final bytes, caption, Page, rights and an owner-only exact or standing policy to a typed Reel intent. Preserve legacy campaign scope and its 100-post limit; the new policy has its own 20-post limit. Build a fake-transport end-to-end vertical slice before scheduling, monitoring or UI integration. Default to organic with zero ad calls. Paid selection uses existing distinct authority; Reel promotion requires a separate future decision. No live provider write, paid generation, deployment or activation is authorized by planning gates.
