## Architecture
The domain owns immutable plan validation and app-scoped reservation, deterministic render-child lineage, cancellation and output inspection. Shared integration owns SQLite schema, routes, worker tick and agent operation registration. Existing admission supplies an immutable authority reference; child admission and artifact commit recheck the current owner, grant and standing policy without serializing credentials or process-local contexts. Desktop uses the existing render service and proof checks. Native iOS shares the Python domain and executes in the foreground through its AVFoundation renderer and trusted byte inspection; existing scene source resolution must support the exact still images bound by the brief. Neither path grants publication or spending authority.
