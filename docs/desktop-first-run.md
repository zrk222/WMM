# Your first useful marketing packet

Start with one app and one job. WMM keeps the research, creative work and results together so you or your agent can take the next useful step.

## Install and open

Preview installers are available under **Artifacts** in a successful [Desktop runtime packages run](https://github.com/zrk222/WMM/actions/workflows/desktop-packages.yml). Choose the intended source revision and its installer, rather than the raw runtime bundle. GitHub requires sign-in to download these artifacts, and the current preview artifacts expire after seven days. These are not permanent release downloads.

| Your computer | Download and start |
| --- | --- |
| Windows | Extract the **WMM-Setup** artifact. Open `WMM-Setup.exe`, complete the per-user installation, then open **Wize Marketing Machine** from Start. Python and a terminal are not needed. |
| Ubuntu 24.04, amd64 | Extract the **WMM-Ubuntu** artifact. Install its `.deb` using your system's package installer, then open **Wize Marketing Machine** from Applications. If no graphical package installer is configured, the command-line fallback is `sudo apt install ./wize-marketing-machine_0.1.0_amd64.deb`. |
| iPhone or iPad | Use the separate [native app and its distribution instructions](../ios/). The desktop installer is not an iOS app. |

The small controller opens your private browser workspace. **Open my workspace** brings it back. Closing the browser leaves approved work running; **Quit WMM** stops this computer's worker. Your computer must stay awake and connected for scheduled work.

Your data stays outside the installed program. Windows uses your local application-data folder; Linux uses `$XDG_DATA_HOME/Wize Marketing Machine` or `~/.local/share/Wize Marketing Machine`. Upgrading or removing the installer preserves that workspace. Windows Credential Manager and an unlocked Linux Secret Service protect supported desktop credentials. The desktop macOS credential adapter is not supported.

## Make one packet

1. **Add your app.** Use **Add an app**, then describe who it helps, the problem it solves and the action a new user should complete. Keep the first goal narrow: for example, get someone to finish their first useful session.
2. **Choose “Find a useful marketing angle.”** Add a real reference you want to study, with its source. A saved reference is research; viral-only qualification still requires 100,000 views and 10× a documented creator baseline.
3. **Inspect the saved work.** Choose **Open your first packet** on **Set your goal**. Read the prepared work, its source records and the missing inputs. This is your first evidence packet; it does not require publication or ad spend.
4. **Take the next useful action.** Revise the brief or creative, add the missing source, or connect your own analytics in **Review results**. Keep the packet and export its report for your agent or teammate.

Core preparation needs no model key or paid account. Connected reads, video tools and campaign execution show their own prerequisites. The goal-specific **Check connections for this goal** control identifies the selected agent and account setup. Owner sign-in is required before inspecting private account readiness or granting authority.

## Let your agent take over

Open **Connect your agent** from the selected goal and follow the [CLI/MCP quickstart](agent-quickstart.md). Choose its app, supported operations, expiry and limits. Review the combined automation agreement before enabling supported autonomous work; local workflow permission and campaign authority remain separately enforced.

Use **Watch the work** for saved progress, **Monitor approved campaigns** for the exact protective monitor, and **Review private campaign outcomes** for saved results and PDF reports. **Advanced tools → Weekly review** brings actionable exceptions together. The receipt distinguishes prepared work, confirmed delivery and observed app results.

Want this work to continue on another computer? Choose the [optional owner-managed always-on path](always-on-runtime.md). It uses that host's own private workspace and account connections; installing the desktop app does not enable a service or move credentials.
