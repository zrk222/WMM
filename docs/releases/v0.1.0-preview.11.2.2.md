# WMM Desktop v0.1.0-preview.11.2.2

Changes since v0.1.0-preview.11.2.1.

**Set up a Facebook Page or Meta campaign from your goal.** In **Check connections for this goal**, go directly to account readiness or choose a WMM-managed assistant or personal agent. Review the Automation agreement to see the exact approved posts, destinations, timing, limits, and work allowed. Automatic publication uses approved batches. New variants remain in review. Signed-out owners can return to the same app’s private campaign measurement after sign-in to inspect tagged visits and linked registrations.

**Control how long Apple checks for files.** Sign in from Apple analytics to return to the selected app’s saved view. Set a stop time on its report-availability watch for up to seven days from setup. The readiness report shows when another read is due or when the window has ended. A November 17 live preflight recorded six Apple report families and zero available files, plus Facebook Page read access. The campaign remained unpublished and its results were unknown.

**Fetch private Apple analytics for your dates.** In **Review results → Search to App Store**, select your dates and choose **Fetch Apple analytics**. WMM uses the selected app’s App Store Connect connection on the owner’s computer to check report inventory, collect available daily files and update the report. The receipt shows which reads ran and whether Apple delivered files for the selected dates. You can reopen the report after collection.

Daily discovery and download files supply impressions, product page views, first-time downloads and redownloads. **Fetch OpenSEO search data** reads the connected project, saves the exact new reading and updates the analysis with its search clicks, impressions and reporting window. Each source keeps its own dates and coverage.

Apple’s daily purchases report supplies estimated proceeds in USD, including signed refunds. The subscription state report supplies the active paid subscription count on the selected end date. WMM keeps that snapshot separate from daily purchase counts. Owners can fetch campaign downloads for an existing approved Apple campaign link, storefront and measurement window. The report identifies the source of each metric and explains when the available files cannot reproduce Apple’s dashboard conversion rate. An Apple-reported zero appears as zero. A missing day stays unknown and includes a next step for collecting the data.

**Turn a finding into a test.** Save the proposed actions and assign each one to an agent with a current grant for that app. The web and App Store analysts can work independently. Once both baselines have verified receipts, a third agent can prepare a test brief for the selected page with a hypothesis, control, metric, observation window and stop rules. The owner can inspect assignments, pending steps and completed receipts in WMM, save a PDF, or download the plan as JSON.

**Resume work after a restart.** Owners can link supported pipeline jobs and provider reads to prerequisite jobs. WMM records the results that allowed the next step to start. An uncertain or changed result flags the dependent work for review. Earlier plan receipts remain available when new evidence changes the recommendation.

The Ubuntu 24.04 amd64 candidate passed fresh installation, upgrade, restart and credential-isolation checks. Desktop and mobile browser tests exercised the report and team assignments using synthetic provider data. Live account acceptance and measured growth remain unverified.
