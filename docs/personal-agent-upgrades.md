# Operate WMM with your personal agent

Grok Bot, Meta Muse, Instinct, Hark Pro, Codex/Dots, Claude Duet and other agents receive one current workflow protocol through `operations.read`. Each named profile retains its own documented host route and unknown capabilities. A manifest update does not connect a cloud agent to your computer or grant account access.

The guide includes every operation in the actual current CLI/MCP catalog, its required inputs and effects, available workflow steps, missing capabilities and a shared protocol hash. Profiles reference that shared protocol instead of repeating it six times. The enclosing guide binds the current app, policy and catalog; changed inputs invalidate the old guide hash.

1. Confirm the actual execution host and app. Read current workspace, operations, permissions, source hashes, open work and receipts.
2. Choose the smallest useful workflow for the owner's acquisition, activation, retention or purchase objective. Validate cheap prerequisites before model, media or provider work.
3. Use current grants and the separate exact campaign scope. Only the owner can approve that scope; an agent cannot approve itself or widen a budget.
4. Run once with a retained request UUID. Read the actual job/artifact/provider result. Reconcile uncertain effects before any replacement request.
5. Report delivery separately from attention and app outcomes, with observed spend, retained commitments, reporting delays, KPI windows/denominators, missing evidence and the next useful action.

## Campaign and creative upgrades

Supported Meta publishing/ad operations require fresh provider permissions, exact Page/account/currency, approved content/rights/targeting hashes, finite resource limits and current runtime readiness. Connecting an account is not campaign authority. Media-budget ceilings exclude taxes, fees and exchange effects. Unknown and paused commitments remain held; OFF attempts a provider pause and needs read-back. Agent monitoring must stay inside its call/time authority and use a separately permitted protective pause if configuration drifts.

Use the eight-piece content-pack preset for coherent draft copy from approved facts. Use Hypit preflight to inspect timing, advisory text density, readiness and matching artifact candidates before submitting a build. Explicit reuse rechecks current source and artifact bytes. Rich media, UGC and stitching use the existing editor/Studio paths. Inspect the actual video and audio; a schema, decoder or API success does not establish creative quality or app conversion.

Runtime validation and state transitions are deterministic. Model wording and marketing performance are not. Provider cache counters are observations; token or financial savings require measured comparable evidence. No agent profile promises growth or silently adds unsupported provider execution.
