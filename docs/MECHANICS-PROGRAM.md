shrinkable properties; danger-zone typing; incremental feature-library modules;
branch hygiene; Preview 10 provenance; comparative HTTP benchmark; dependency freshness.

Only completed PRs and actual observations count as acceptance. Branch totals,
signing, independent human/security review and marketing outcomes are separate
facts. A branch-count target cannot justify deleting unmerged or active work.
No framework switch is authorized by a benchmark plan alone.

shrinkable properties and danger-zone typing are in separate stacked PRs
