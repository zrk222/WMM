# WMM marketer tool and human/agent parity acceptance

Required by the owner October24,2026. This is additive to every existing UPG;
no missing workflow, disabled action, saved packet or roadmap satisfies delivery.

A marketer must take one product from a specific audience problem to a campaign,
deliver the campaign, see actual business results and decide what to change.
Every row below requires discoverable human UI and matching typed agent operations
over the same state, shared previews/exports and explicit operating scope. Product
activation is separate from software acceptance. Provider setup is an onboarding
state; missing product implementation remains an implementation gap.

For every tool, acceptance must name inputs, actual output, current human action,
agent operation, required credentials/scopes, effect classification, approval,
cost/unknown-cost rule, telemetry, idempotency, restart/cancel/reconcile, tests and
report/export. No plan row may be counted complete from source presence alone.
Test the campaign cross-channel claim/offer/CTA consistency, real expiry rather
than fake urgency, rights boundaries and source/maturity/currency gaps. Viral
qualification is an observed-count rule, not a guarantee of a future viral result.

## Hypit and OpenCut control requirements

Use the complete upstream control surface as a source-backed inventory. Prefer
Hypit's existing authoring/runtime/Studio interfaces and public package Companion
ABI for their actual functions. Reuse OpenCut's usable editor concepts or licensed
code through a reviewed pinned adapter/rebuild when useful. Preserve MIT notices
if source is copied. New OpenCut roadmap features are not current functionality.
Do not block WMM delivery on an upstream rewrite or discard existing Classic
controls solely because Classic is archived.

OpenCut Classic public source commit cf5e79e919144200294fb9fed22a222592a0aeea.
