This is an offline parser for synthetic or separately authorized Apple App Downloads Standard report segments. It has no network, credential, database or user-interface access. The selected segment list must be attested complete by its caller; this module cannot verify provider pagination or authenticity. It validates Apple's published MD5 checksum only for transfer consistency; MD5 is not a cryptographic authenticity guarantee. SHA-256 identifies observed bytes for provenance and is not a signature. Report download, multi-report ingestion, persistence, scheduling, UI, provider validation and the full WMM goal remain incomplete. Accessibility is not applicable because this increment adds no UI. Synthetic tests are not actual Apple or device acceptance.
