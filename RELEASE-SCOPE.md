# Public packaging acceptance

This release distributes a self-contained Python local application with generic
example workspaces. It contains no owner app profiles, credentials, production
databases, internal research, private receipts or history. The application starts
without provider credentials and retains isolated data between restarts.
Host/CSRF validation and spending/write restrictions remain enabled. Optional
provider setup requires the installer's own supported accounts and tools.
The release does not claim full autonomous distribution or measured growth.
